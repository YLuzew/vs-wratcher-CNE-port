# VS Wratcher · Codename Engine 移植版

把 VS Wratcher 移植到 Codename Engine 的版本。

原版模组已经废弃，而且构建在旧版本的 Psych Engine（PE）上。这一版把内容重新做在 Codename Engine 上，并补齐了手机端适配。

原版模组的Youtube : https://youtu.be/frGinNRhmpI?si=6keb6EBQ6XkV0dNK

## 原版与这一版

| | |
| --- | --- |
| 原版状态 | 已废弃，不再维护 |
| 原版引擎 | 旧版本 Psych Engine |
| 本版引擎 | Codename Engine |
| 主要平台 | 手机端（Android） |

原版基于旧引擎的部分不能直接照搬，歌曲、角色、舞台与演出脚本都需要在 Codename Engine 上重做。

## 制作人员

- **Luzew / Yubu** —— 移植与其余内容
- **长夜-Official** —— Story Mode 界面代工

## 引擎

本版基于 [Codename Engine](https://github.com/CodenameCrew/CodenameEngine) 构建，这是一个面向 FNF 的可扩展模组框架，各平台构建可从官方仓库获取。

这个源码目录本身也能直接放进 Codename 的 `mods` 文件夹里当模组运行。
